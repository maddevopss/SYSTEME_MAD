# Template — Prospection douce MAD DevOps

## Objectif

Ce template sert à ouvrir une conversation commerciale sans pression, sans automatisme agressif et sans jargon.

---

## Principe

```text
Conversation avant vente.
Clarté avant proposition.
Respect avant relance.
```

---

# 1. Message initial

```text
Bonjour [Nom],

Je me permets de vous écrire parce que j’ai remarqué que [contexte observé / type d’activité / besoin possible].

Je travaille avec MAD DevOps sur des outils numériques simples pour aider les petites entreprises à réduire les tâches répétitives, les fichiers dispersés ou les processus qui prennent trop de temps.

Si jamais vous avez un irritant de ce genre, je serais heureux d’en discuter simplement pour voir si ça vaut la peine d’être clarifié.

Bonne journée,
Marc-André Dufour
MAD DevOps
```

---

# 2. Relance légère

```text
Bonjour [Nom],

Je me permets une petite relance concernant mon message précédent.

Aucune pression de mon côté. Si ce n’est pas un besoin actuel, aucun souci.

Si jamais vous souhaitez clarifier un irritant ou une tâche répétitive dans vos opérations, je peux vous proposer un court échange.

Bonne journée,
Marc-André
```

---

# 3. Réponse si intérêt

```text
Merci pour votre retour.

La meilleure prochaine étape serait un court échange pour comprendre votre contexte avant de proposer quoi que ce soit.

L’objectif serait de voir ce qui est réellement utile, ce qui est prioritaire et ce qui devrait rester hors périmètre pour une première version.
```

---

# 4. Réponse si refus ou silence

```text
Merci pour votre réponse.

Aucun problème. Je vous souhaite une excellente continuation, et je reste disponible si un besoin de clarification ou d’outil numérique simple apparaît plus tard.
```

---

## Règle d’usage

Ne pas relancer indéfiniment.

Une relance suffit, sauf si la personne a explicitement demandé un suivi plus tard.
