# PLAY-017 — Appel découverte commerciale

## Objectif

Guider un appel découverte avec un prospect sans vendre trop vite et sans tomber dans le jargon technique.

---

## Principe

```text
Comprendre avant de proposer.
Clarifier avant de chiffrer.
Limiter avant de promettre.
```

---

# 1. Ouvrir l’appel

Formulation recommandée :

```text
Parfait, je vais commencer par comprendre votre besoin avant de proposer une solution. L’objectif est de voir ce qui serait réellement utile, ce qui est prioritaire, et ce qui devrait rester hors périmètre pour une première version.
```

---

# 2. Comprendre le contexte

Questions utiles :

- Qu’est-ce qui vous a donné envie d’en parler maintenant ?
- Comment faites-vous actuellement ?
- Qu’est-ce qui prend trop de temps ?
- Qu’est-ce qui crée le plus de flou ?
- Qui est touché par ce problème ?

---

# 3. Identifier la première version utile

Questions utiles :

- Si on réglait seulement une chose, ce serait quoi ?
- Quel résultat rendrait le projet utile rapidement ?
- Qu’est-ce qui peut attendre ?
- Qu’est-ce qui serait clairement hors périmètre au départ ?

---

# 4. Ne pas chiffrer trop tôt

Si le prospect demande un prix trop vite :

```text
Je pourrais vous donner un chiffre rapide, mais il risquerait d’être faux. Pour vous répondre correctement, il faut d’abord clarifier le besoin, les limites et ce qui serait réellement utile dans une première version.
```

---

# 5. Sortie attendue

À la fin de l’appel, il faut savoir :

```text
le problème principal,
le contexte,
la première version utile,
les limites,
la prochaine action.
```

---

## Prochaine action possible

- envoyer un résumé;
- proposer un cadrage court;
- préparer une proposition;
- recommander de reporter;
- refuser poliment si le mandat est mal aligné.
