# Fiche réflexe fondateur MAD DevOps

## Objectif

Savoir quoi faire sans réfléchir trop longtemps.

Cette fiche sert dans les moments de surcharge, de flou ou de reprise après interruption.

---

## Règle générale

```text
Si c’est flou, on clarifie.
Si ça bloque, on identifie la prochaine action.
Si ça revient souvent, on améliore le système.
```

# Minimum vital

Quand la journée est chaotique, faire seulement ceci :

```text
1. Identifier une prochaine action.
2. Faire une relance importante.
3. Noter un apprentissage ou une célébration.
```

---

# Questions de reprise rapide

```text
Où j’en suis ?
Qu’est-ce qui bloque ?
Qui attend quoi ?
Quelle est la prochaine action ?
Qu’est-ce que je peux simplifier ?
```

---

## Phrase de rappel

```text
Le système existe pour réduire le flou, pas pour devenir une autre charge mentale.
```
