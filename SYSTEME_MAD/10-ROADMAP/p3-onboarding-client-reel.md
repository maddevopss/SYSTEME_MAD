# P3 — Onboarding client réel

## Rôle du document

Ce document décrit le parcours d’activation d’un premier client réel dans MADSuite.

Objectif : accompagner le client sans créer une dépendance lourde ni promettre du développement sur mesure.

---

## Principe

```text
Onboarding simple = valeur rapide
Premier client = validation terrain
Accompagnement ≠ consultation illimitée
```

---

# 1. Avant l’activation

Vérifier :

```text
P2 fermée
P3 officiellement ouverte
CHK-080 readiness premiers clients validée
CHK-085 onboarding premier client consultée
CHK-091 pricing/offres cohérente
CHK-094 readiness commerciale minimale prête
```

---

# 2. Préqualification

Confirmer :

```text
client correspond au profil idéal
besoin temps/projets/factures réel
complexité raisonnable
aucune intégration critique absente
attentes réalistes
```

---

# 3. Configuration initiale

Créer ou vérifier :

```text
organisation
utilisateur principal
plan choisi
trial ou abonnement
modules activés
client exemple
projet exemple
```

Ne pas activer par défaut :

```text
module sensible non expliqué
desktop-agent sans consentement clair
fonctionnalité expérimentale non nécessaire
```

---

# 4. Première valeur à obtenir

Le client doit réussir à faire au moins un parcours :

```text
créer un client
créer un projet
ajouter ou suivre du temps
préparer une facture
comprendre le portail facture
```

---

# 5. Suivi après activation

Suivi recommandé :

```text
jour 0 : activation et premier parcours
jour 1 : vérifier blocage majeur
jour 3 : recueillir irritants
jour 7 : vérifier usage réel
jour 14 : décider poursuite, conversion ou ajustement
```

---

# 6. Feedback à collecter

```text
ce qui est clair
ce qui est confus
ce qui sauve du temps
ce qui bloque la facturation
ce qui manque vraiment
ce qui est inutile
prix perçu
volonté de payer ou continuer
```

---

# 7. Limites à rappeler

```text
MADSuite est en validation encadrée
les prix V1 sont une hypothèse de lancement
les modules sensibles ne sont pas activés sans explication
le support initial aide à démarrer, mais ne remplace pas une implantation sur mesure
```
