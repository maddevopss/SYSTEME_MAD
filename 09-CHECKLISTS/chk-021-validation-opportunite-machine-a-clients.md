# CHK-021 — Validation d’une opportunité Machine à clients

## Objectif

Valider qu’une opportunité commerciale est suffisamment claire, pertinente et actionnable avant de la faire avancer dans le pipeline commercial CerveauMAD.

Cette checklist évite de transformer un simple signal flou en priorité commerciale artificielle.

## Principe

```text
Une opportunité commerciale valide doit avoir un besoin clair, une offre possible et une prochaine action humaine.
```

Une opportunité non claire doit être qualifiée, reportée ou fermée.

---

## Checklist

### 1. Signal

- [ ] Le signal est identifié.
- [ ] La source du signal est claire.
- [ ] Le signal n’est pas seulement une intuition sans contexte.

---

### 2. Contact ou organisation

- [ ] Le contact, client ou type d’organisation est identifié.
- [ ] Le canal d’entrée est connu ou approximé.
- [ ] Il existe une façon réaliste de reprendre contact.

---

### 3. Besoin ou problème

- [ ] Le besoin semble réel.
- [ ] Le problème est formulé simplement.
- [ ] Le besoin n’est pas inventé pour pousser une offre.
- [ ] Le niveau de clarté est indiqué.

---

### 4. Offre possible

- [ ] Une offre MAD DevOps peut raisonnablement répondre au besoin.
- [ ] L’offre reste compréhensible pour une personne non technique.
- [ ] L’offre ne promet pas une capacité inexistante.
- [ ] L’offre peut être cadrée simplement.

---

### 5. Priorité commerciale

- [ ] Une priorité est choisie : P0, P1, P2, P3 ou Refus.
- [ ] La priorité est justifiée par l’utilité commerciale réelle.
- [ ] L’opportunité ne monte pas en priorité seulement parce qu’elle est récente.

---

### 6. Prochaine action

- [ ] La prochaine action commence par un verbe.
- [ ] La prochaine action est courte et humaine.
- [ ] La prochaine action indique quoi faire ensuite.
- [ ] L’opportunité peut être reprise sans reconstruire le contexte.

---

### 7. Raccordement

- [ ] L’opportunité est raccordée au pipeline commercial.
- [ ] La trace est suffisante.
- [ ] Le tableau de bord Machine à clients est mis à jour si l’opportunité est prioritaire.
- [ ] Le registre CerveauMAD conserve la trace si nécessaire.

---

### 8. Garde-fous

- [ ] Aucune promesse exagérée.
- [ ] Aucun jargon inutile.
- [ ] Aucune pression commerciale artificielle.
- [ ] Aucun besoin inventé.
- [ ] Aucun suivi inutile si l’opportunité est morte.

---

## Résultat de validation

- [ ] Validée — avancer dans le pipeline
- [ ] À qualifier
- [ ] À clarifier avec le contact
- [ ] À mettre au backlog commercial
- [ ] À fermer
- [ ] À archiver
- [ ] À refuser

---

## Critères d’acceptation

Une opportunité est acceptée si :

1. le signal est compréhensible;
2. le contact ou l’organisation est identifiable;
3. le besoin est plausible;
4. une offre possible existe;
5. la priorité est justifiée;
6. la prochaine action est claire;
7. la trace est suffisante;
8. les garde-fous commerciaux sont respectés.
