# Résumé exécutif — intégration des idées MADSuite

Les 36 sources du lot de juillet 2026 ont été transformées en un portefeuille de 36 entrées officielles. Toutes les idées sont conservées, mais leur code n’est pas adopté tel quel.

La première priorité est le domaine `customer_growth`, construit comme une tranche verticale sécurisée et sans duplication. Les autres programmes sont ordonnés selon leurs dépendances et leur niveau de preuve.

Le standard MADPROOF, la non-duplication et les validations locales sont obligatoires avant toute promotion.
