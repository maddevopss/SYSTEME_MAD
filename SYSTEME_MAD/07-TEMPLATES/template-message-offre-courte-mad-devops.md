# Template — Message offre courte MAD DevOps

## Objectif

Fournir un message court pour transformer une opportunité qualifiée en prochaine étape commerciale claire.

Ce template sert à répondre rapidement sans écrire une proposition complète trop tôt.

## Message court

```text
Bonjour [Nom],

Merci pour les détails.

Voici ce que je comprends : [résumer le besoin en une phrase simple].

Je pense pouvoir t’aider avec [type d’aide / format simple], pour [résultat attendu ou friction à réduire].

La meilleure prochaine étape serait de [prochaine action simple : appel court, mini-diagnostic, cadrage, estimation rapide].

Si ça te convient, je peux te proposer [option simple / moment / façon de commencer].

Merci,
Marc-André
MAD DevOps
```

---

## Version ultra-courte

```text
Bonjour [Nom],

Ce que je comprends : [besoin].

Je peux t’aider à [résultat] avec [format simple].

Prochaine étape proposée : [action simple].

Merci,
Marc-André
```

---

## Champs à remplacer

| Champ | Rôle |
|---|---|
| `[Nom]` | Nom du contact. |
| `[besoin]` | Besoin résumé simplement. |
| `[type d’aide]` | Diagnostic, mini-mandat, automatisation, site Web, outil interne, etc. |
| `[résultat]` | Résultat attendu ou friction réduite. |
| `[action simple]` | Prochaine étape claire. |

---

## Garde-fous

- Garder le message court.
- Résumer le besoin avant de proposer.
- Ne pas promettre un résultat non validé.
- Ne pas utiliser de jargon technique inutile.
- Proposer une seule prochaine étape.
- Ne pas transformer ce message en proposition complète.
