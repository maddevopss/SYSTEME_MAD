# Notes d’implémentation — programme d’idées MADSuite

Les travaux de code seront découpés par dépôt et par intention. Le référentiel ne doit pas recevoir de code exécutable provenant du lot source. Les dépôts de développement doivent recevoir leurs propres ADR, TODO et validations avant toute implémentation.
