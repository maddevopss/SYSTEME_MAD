# Index — Décisions

## Rôle du dossier

Ce dossier contient les décisions structurantes du Système MAD.

Une décision sert à documenter un choix important, son contexte, sa justification, ses conséquences et les documents liés.

## Règles d’usage

- Créer une décision lorsqu’un choix structure durablement le Système MAD.
- Documenter le contexte et les conséquences.
- Relier la décision aux guides, plays, checklists ou produits concernés.
- Éviter de transformer une préférence temporaire en décision officielle.
- Réviser une décision si le contexte change significativement.
