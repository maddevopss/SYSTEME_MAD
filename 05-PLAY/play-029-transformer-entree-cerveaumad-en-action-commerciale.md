# PLAY-029 — Transformer une entrée CerveauMAD en action commerciale

## Objectif

Relier CerveauMAD à la machine à clients de MAD DevOps.

Ce playbook sert à transformer une entrée CerveauMAD en action commerciale concrète : prospect, suivi, offre, proposition, preuve client, amélioration du site, pipeline ou prochaine action de vente.

## Principe

```text
Une idée utile doit pouvoir devenir une action commerciale claire.
```

La machine à clients ne force pas la vente.

Elle transforme les signaux utiles en actions concrètes, humaines et alignées avec MAD DevOps.

---

## Quand utiliser ce playbook

Utiliser ce playbook lorsqu’une entrée CerveauMAD touche :

- un prospect;
- un client;
- une offre;
- une proposition;
- une preuve client;
- une amélioration du site;
- une opportunité commerciale;
- un suivi à faire;
- une demande entrante;
- une idée qui peut aider à vendre sans bullshit.

---

## Étape 1 — Identifier le potentiel commercial

Répondre rapidement :

1. Est-ce que cette entrée peut aider à obtenir un client ?
2. Est-ce qu’elle peut aider à mieux servir un client ?
3. Est-ce qu’elle clarifie une offre ?
4. Est-ce qu’elle peut devenir une preuve client ?
5. Est-ce qu’elle mérite un suivi ?
6. Est-ce qu’elle doit aller dans le pipeline ?

Si la réponse est non partout, l’entrée n’est pas commerciale.

Elle doit rester dans le registre CerveauMAD, le backlog ou être refusée.

---

## Étape 2 — Classer l’action commerciale

| Type | Destination |
|---|---|
| Prospect à contacter | Pipeline commercial |
| Demande entrante | Parcours client |
| Offre à clarifier | Guide offre ou backlog commercial |
| Proposition à préparer | Template proposition client |
| Preuve à produire | Portfolio / preuve sociale |
| Suivi à faire | Suivi client / pipeline |
| Amélioration site | Backlog site Web |
| Apprentissage commercial | Fiche apprentissage / registre |

---

## Étape 3 — Choisir la prochaine action

Une prochaine action commerciale doit être simple et directe.

Exemples :

- ajouter le prospect au pipeline;
- préparer un message de suivi;
- clarifier le besoin en Phase 0;
- créer une fiche de qualification;
- rédiger une proposition courte;
- ajouter une preuve client;
- améliorer une section du site;
- transformer une idée en offre testable;
- reporter à la revue commerciale hebdomadaire.

---

## Étape 4 — Appliquer les garde-fous MAD DevOps

Avant d’agir, vérifier :

- [ ] l’action aide vraiment un client ou un prospect;
- [ ] l’action ne crée pas une promesse exagérée;
- [ ] l’action reste compréhensible pour une personne non technique;
- [ ] l’action respecte le ton MAD DevOps : simple, humain, clair;
- [ ] l’action ne vend pas une capacité qui n’existe pas encore;
- [ ] l’action évite le jargon inutile;
- [ ] l’action mène à une prochaine étape concrète.

---

## Étape 5 — Raccorder au bon système

| Besoin | Document ou espace |
|---|---|
| Ajouter ou suivre un prospect | Pipeline commercial |
| Qualifier une demande | Template qualification demande entrante |
| Préparer une proposition | Template proposition client |
| Structurer une offre | Guide offre simple / offres packagées |
| Créer une preuve client | Portfolio / preuve sociale |
| Revoir une opportunité | Revue pipeline commercial |
| Garder une trace | Registre CerveauMAD |
