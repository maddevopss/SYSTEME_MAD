# Template — Calendrier mensuel Early Access MADSuite

## Rôle du template

Ce template sert à organiser le cycle mensuel Early Access MADSuite.

Il aide à placer dans le mois les actions récurrentes : suivi métriques, feedback, revue, plan d’action et bilan de fin de mois.

## Règle d’or

Le calendrier doit rendre le cycle mensuel visible sans ajouter une surcharge de gestion.

# Structure recommandée

## 1. Informations du mois

```text
Mois :
Responsable :
Version produit :
Objectif principal :
```

---

## 2. Semaine 1 — Lancement du mois

Objectif : transformer le bilan précédent en plan d’action.

- [ ] Relire le bilan du mois précédent.
- [ ] Confirmer l’objectif du mois.
- [ ] Définir les priorités P0/P1/P2.
- [ ] Mettre à jour le plan d’action mensuel.
- [ ] Vérifier les documents à mettre à jour.

Documents utiles :

```text
SYSTEME_MAD/07-TEMPLATES/template-bilan-fin-mois-early-access-madsuite.md
SYSTEME_MAD/07-TEMPLATES/template-plan-action-mensuel-early-access-madsuite.md
```

---

## 3. Semaine 2 — Suivi activation

Objectif : vérifier si les utilisateurs avancent vers la première valeur.

- [ ] Vérifier les demandes Early Access.
- [ ] Vérifier les activations.
- [ ] Vérifier les premières actions utiles.
- [ ] Vérifier les premières factures.
- [ ] Noter les signaux à surveiller.

Documents utiles :

```text
SYSTEME_MAD/07-TEMPLATES/template-dashboard-metriques-early-access-madsuite.md
SYSTEME_MAD/09-CHECKLISTS/chk-039-validation-dashboard-metriques-early-access-madsuite.md
```

---

## 4. Semaine 3 — Feedback et ajustements

Objectif : transformer les retours en signaux utiles.

- [ ] Regrouper les feedbacks reçus.
- [ ] Identifier les tendances.
- [ ] Mettre à jour le backlog post-feedback.
- [ ] Identifier les ajustements simples à faire avant la fin du mois.
- [ ] Reporter ce qui n’est pas prioritaire.

Documents utiles :

```text
SYSTEME_MAD/05-PLAY/play-039-analyse-feedback-early-access-madsuite.md
SYSTEME_MAD/07-TEMPLATES/template-backlog-post-feedback-early-access-madsuite.md
```

---

## 5. Semaine 4 — Revue et bilan

Objectif : fermer le mois et préparer le suivant.

- [ ] Produire ou mettre à jour le rapport mensuel.
- [ ] Faire la revue mensuelle.
- [ ] Produire le bilan fin de mois.
- [ ] Valider le bilan avec `CHK-040`.
- [ ] Préparer l’entrée du prochain plan d’action.

Documents utiles :

```text
SYSTEME_MAD/07-TEMPLATES/template-rapport-mensuel-early-access-madsuite.md
SYSTEME_MAD/05-PLAY/play-040-revue-mensuelle-early-access-madsuite.md

```
