# PLAY-021 — Revue du pipeline commercial MAD DevOps

## Objectif

Effectuer une revue courte du pipeline commercial pour garder les opportunités claires, les relances propres et les prochaines actions visibles.

---

## Principe

```text
Moins de flou.
Moins d’oubli.
Une prochaine action par opportunité.
```

---

# 1. Ouvrir le tableau pipeline

Utiliser :

```text
template-tableau-pipeline-commercial-mad-devops.md
```

---

# 2. Revoir les nouvelles demandes

Pour chaque nouvelle demande :

- vérifier le besoin résumé;
- qualifier rapidement;
- choisir une issue;
- créer une prochaine action.

---

# 3. Revoir les relances

Pour chaque relance :

- confirmer si elle est encore pertinente;
- envoyer un message simple;
- fermer si la relance n’a plus de valeur;
- éviter les relances infinies.

---

# 4. Revoir les propositions

Pour chaque proposition ouverte :

- vérifier la date d’envoi;
- vérifier la prochaine action;
- prévoir une relance respectueuse;
- décider si elle reste ouverte, reportée, gagnée ou perdue.

---

# 5. Revoir les preuves client

Pour chaque projet livré :

- décider si une preuve client est pertinente;
- demander autorisation si nécessaire;
- créer fiche projet ou étude de cas.

---

## Critère de réussite

La revue est réussie si chaque opportunité a un état clair et une prochaine action réaliste.
