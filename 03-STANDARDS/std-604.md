# STD-604 — Archivage documentaire

## Règle d’or

Archiver, ce n’est pas jeter; c’est retirer un document de la source active sans perdre son contexte.

---

## Objectif

Définir les règles d’archivage documentaire du Système MAD.

L’archivage sert à préserver l’historique tout en évitant la confusion avec les documents officiels.

---

## Règles obligatoires

- Un document archivé ne doit plus être traité comme source officielle.
- Un document archivé doit conserver assez de contexte pour être compris plus tard.
- Les archives doivent être placées dans `99-ARCHIVES/` ou dans un sous-dossier d’archives clairement identifié.
- Si un document officiel remplace une archive, le nouveau document doit être identifiable.
- Les agents IA ne doivent pas utiliser les archives comme source principale sans demande explicite.

---

## Bonnes pratiques

✔ Ajouter une note indiquant pourquoi le document est archivé.

✔ Préserver la date et l’auteur original lorsque possible.

✔ Ne pas archiver un document si son contenu doit d’abord être fusionné.

✔ Garder les archives consultables, mais séparées de la documentation active.

✔ Éviter de modifier lourdement une archive après son classement.

---

## Anti-patterns

### Mauvais

Laisser un document obsolète dans un dossier actif.

### Mauvais

Supprimer un document historique sans conserver les décisions importantes.

### Mauvais

Demander à un agent IA d’utiliser tout le dépôt sans exclure les archives.

---

## Cas réel Système MAD

Les anciens dossiers `HANDBOOK/`, `BOOTSTRAP/`, `CHECKLIST/` ou fichiers racine doivent être archivés ou remplacés par les versions officielles situées dans `SYSTEME_MAD/`.
