# CHK-039 — Validation dashboard métriques Early Access MADSuite

## Objectif

Cette checklist valide qu’un dashboard métriques Early Access MADSuite est clair, utile et orienté décision.

Elle doit être utilisée avant de publier, partager ou utiliser le dashboard dans une revue mensuelle.

## 1. Identification

- [ ] La période affichée est claire.
- [ ] La dernière mise à jour est indiquée.
- [ ] La version produit est indiquée.
- [ ] Le segment utilisateur est indiqué si pertinent.
- [ ] Les sources de données sont identifiées.

---

## 2. Vue synthèse

- [ ] Les demandes Early Access sont visibles.
- [ ] Les invitations envoyées sont visibles.
- [ ] Les activations sont visibles.
- [ ] Les premières actions utiles sont visibles.
- [ ] Les premières factures sont visibles.
- [ ] Les feedbacks reçus sont visibles.
- [ ] Les items P0/P1 ouverts sont visibles.

---

## 3. Funnel Early Access

- [ ] Les étapes du funnel sont dans le bon ordre.
- [ ] Les volumes sont lisibles.
- [ ] Les conversions importantes sont visibles.
- [ ] L’étape la moins fluide est identifiable.
- [ ] Le dashboard aide à savoir quoi améliorer.

---

## 4. Première valeur

- [ ] Le temps vers premier client est suivi si disponible.
- [ ] Le temps vers première facture est suivi si disponible.
- [ ] Le taux de première facture est suivi si disponible.
- [ ] Le PDF ou les montants dus sont suivis si pertinents.
- [ ] Le dashboard montre clairement ce qui ralentit la première valeur.

---

## 5. Revenue Core

- [ ] Les parcours clients sont couverts.
- [ ] Les parcours projets sont couverts si pertinents.
- [ ] Les parcours temps sont couverts.
- [ ] Les parcours factures sont couverts.
- [ ] Les parcours PDF sont couverts.
- [ ] Les parcours estimés sont couverts si pertinents.
- [ ] Les parcours paiements sont couverts si pertinents.
- [ ] Les parcours revenus sont couverts.

---

## 6. Feedback

- [ ] Les feedbacks reçus sont visibles.
- [ ] Les feedbacks analysés sont visibles si disponibles.
- [ ] Les principales catégories de feedback sont visibles.
- [ ] Les top signaux sont résumés.
- [ ] Les signaux restent reliés à des parcours produit.

---

## 7. Backlog

- [ ] Les items P0/P1 ouverts sont visibles.
- [ ] Les items P2/P3 ne prennent pas toute la place.
- [ ] Les priorités sont reliées à un signal clair.
- [ ] Le dashboard aide à choisir la prochaine action.

---

## 8. Simplicité

- [ ] Le dashboard ne contient pas de métriques inutiles.
- [ ] Chaque section aide une décision.
- [ ] Les libellés sont compréhensibles.
- [ ] Les tendances sont faciles à lire.
- [ ] Le dashboard peut être compris rapidement.

---

## 9. Verdict

- [ ] Prêt à utiliser.
- [ ] Prêt avec corrections mineures.
- [ ] À simplifier.
- [ ] À reprendre.
