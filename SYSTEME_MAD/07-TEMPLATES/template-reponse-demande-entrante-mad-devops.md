# Template — Réponse à une demande entrante MAD DevOps

## Objectif

Répondre rapidement et professionnellement à une demande reçue, sans promettre trop tôt et sans chiffrer avant clarification.

---

## Réponse standard

```text
Bonjour [Nom],

Merci pour votre message.

J’ai bien reçu votre demande concernant [résumé bref du besoin]. Avant de vous proposer une solution ou une estimation, j’aimerais clarifier quelques éléments pour bien comprendre votre contexte et éviter de partir dans la mauvaise direction.

La prochaine étape la plus simple serait un court échange pour comprendre le besoin, les priorités et ce qui serait utile dans une première version.

Est-ce que vous seriez disponible pour un appel découverte ?

Merci,
Marc-André Dufour
MAD DevOps
```

---

## Réponse si le besoin est trop flou

```text
Bonjour [Nom],

Merci pour votre message.

Votre idée semble intéressante, mais il manque encore quelques éléments pour bien comprendre le besoin. Je vous proposerais de commencer par une courte clarification avant de parler de solution ou de prix.

L’objectif serait de cerner le problème réel, les priorités et les limites d’une première version utile.

Merci,
Marc-André Dufour
MAD DevOps
```

---

## Réponse si ce n’est pas aligné

```text
Bonjour [Nom],

Merci pour votre message et votre confiance.

Après lecture, je ne suis pas certain que MAD DevOps soit le meilleur choix pour ce besoin précis. Je préfère être transparent plutôt que de vous engager dans une mauvaise direction.

Je vous souhaite une bonne suite dans vos démarches.

Merci,
Marc-André Dufour
MAD DevOps
```
