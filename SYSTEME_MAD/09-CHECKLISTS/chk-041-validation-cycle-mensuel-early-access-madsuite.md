# CHK-041 — Validation cycle mensuel Early Access MADSuite

## Objectif

Cette checklist valide que le cycle mensuel Early Access MADSuite est complet, utile et léger.

Elle sert à vérifier que chaque étape du mois produit un livrable clair et une décision exploitable.

## 1. Ouverture du mois

- [ ] Le bilan du mois précédent a été relu.
- [ ] L’objectif principal du mois est clair.
- [ ] Les priorités P0/P1/P2 sont définies.
- [ ] Le plan d’action mensuel est à jour.
- [ ] Les documents à mettre à jour sont identifiés.

---

## 2. Suivi des métriques

- [ ] Le dashboard métriques est à jour.
- [ ] Les demandes Early Access sont suivies.
- [ ] Les activations sont suivies.
- [ ] Les premières actions utiles sont suivies.
- [ ] Les premières factures sont suivies si disponibles.
- [ ] Les items P0/P1 ouverts sont visibles.

---

## 3. Analyse feedback

- [ ] Les feedbacks du mois sont regroupés.
- [ ] Les signaux importants sont identifiés.
- [ ] Les signaux sont liés au Revenue Core lorsque pertinent.
- [ ] Le backlog post-feedback est mis à jour.
- [ ] Les demandes non prioritaires sont reportées avec une raison courte.

---

## 4. Revue mensuelle

- [ ] La revue mensuelle a été tenue ou planifiée.
- [ ] Les constats principaux sont clairs.
- [ ] Les décisions du mois sont visibles.
- [ ] Les priorités du mois suivant sont préparées.
- [ ] Les documents à mettre à jour sont listés.

---

## 5. Fermeture du mois

- [ ] Le bilan fin de mois est produit.
- [ ] `CHK-040` est appliquée au bilan.
- [ ] Les actions réalisées sont distinguées des actions reportées.
- [ ] Les apprentissages du mois sont notés.
- [ ] L’entrée du prochain mois est claire.

---

## 6. Synthèse exécutive

- [ ] La situation actuelle est résumée clairement.
- [ ] Le signal clé est indiqué.
- [ ] La décision principale est indiquée.
- [ ] Le risque principal est indiqué.
- [ ] La priorité suivante est indiquée.

---

## 7. Garde-fous

- [ ] Le cycle reste léger.
- [ ] Les priorités restent limitées.
- [ ] Le cycle ne crée pas de gestion inutile.
- [ ] Les décisions restent liées au produit réel.
- [ ] Le positionnement non médical de MADSuite est respecté.

---

## 8. Verdict

- [ ] Cycle mensuel complet.
- [ ] Cycle complet avec corrections mineures.
- [ ] Cycle incomplet.
- [ ] Cycle à simplifier.
