# BOOT-002 — Frontend React

> **Objectif**
>
> Fournir une fondation professionnelle, simple et évolutive pour le développement d'interfaces Web avec React, conforme au Système MAD.

---

# Vision

BOOT-002 n'est pas un projet visuel de démonstration.

C'est une base de départ pour créer rapidement une interface claire, maintenable et connectée à une API.

---

# Objectifs

- Réduire le temps de démarrage d'un frontend
- Uniformiser la structure des interfaces
- Appliquer les Standards MAD
- Faciliter l'intégration avec une API
- Améliorer la cohérence UX
