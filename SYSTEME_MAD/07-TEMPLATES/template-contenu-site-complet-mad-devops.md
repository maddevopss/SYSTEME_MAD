# 7. FAQ

## Est-ce que je dois connaître la technologie ?

```text
Non. L’objectif est de comprendre votre besoin en langage simple avant de parler de solution technique.
```

## Est-ce possible de commencer petit ?

```text
Oui. MAD DevOps privilégie une première version utile plutôt qu’un gros projet flou.
```

## Pouvez-vous donner un prix rapidement ?

```text
Un prix sérieux demande d’abord de clarifier le besoin, le périmètre et les limites d’une première version.
```
