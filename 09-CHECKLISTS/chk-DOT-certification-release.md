# CHK-DOT — Certification d’une release MADSuite

## Statut de l’identifiant

`DOT` est un identifiant temporaire en attente d’attribution dans le registre documentaire. Il est conservé afin d’éviter une rupture de liens.

## Périmètre

- [ ] La version candidate est identifiée.
- [ ] Les dépôts et domaines touchés sont listés.
- [ ] Les changements sensibles sont signalés.

## Validations

- [ ] Les profils applicables ont été exécutés.
- [ ] Les gates critiques exigés par `STD-800` sont couverts.
- [ ] Les échecs, réserves et éléments non démontrés sont explicités.
- [ ] Les preuves sont accessibles et liées à une exécution précise.
- [ ] Les artefacts ne contiennent ni secret ni donnée personnelle.

## Décision

- [ ] La décision finale est explicite.
- [ ] Les conditions d’un éventuel `CONDITIONAL_GO` sont écrites.
- [ ] Le certificat est versionné et archivé.
- [ ] Les connaissances stabilisées à remonter dans `SYSTEME_MAD` sont identifiées.

> Cette checklist guide l’exécution, mais ne constitue jamais une preuve d’exécution en soi.
