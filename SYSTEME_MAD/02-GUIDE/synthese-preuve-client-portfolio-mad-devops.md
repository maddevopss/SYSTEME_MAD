# Synthèse preuve client et portfolio MAD DevOps

## Objectif

Relier la livraison client, les témoignages, les références, les autorisations, les fiches publiques, les études de cas et le portfolio dans une chaîne cohérente.

Cette synthèse sert à transformer une livraison réussie en preuve utile, sans pression commerciale et sans exposer d’information sensible.

---

## Principe central

```text
Prouver sans exposer.
Montrer la valeur sans trahir la confiance.
```

---

## Chaîne complète

```text
Livraison acceptée
→ valeur comprise
→ type de preuve choisi
→ autorisation ou anonymisation
→ témoignage / référence / fiche projet / étude de cas
→ validation public / privé
→ portfolio ou usage privé
→ apprentissage commercial
```

## Types de preuves possibles

| Type | Usage |
|---|---|
| Témoignage court | Rassurer un prospect rapidement. |
| Référence privée | Appuyer une discussion commerciale sans publication publique. |
| Fiche projet publique | Montrer un problème réglé et une valeur livrée. |
| Étude de cas anonymisée | Expliquer plus en détail sans exposer le client. |
| Capture autorisée | Montrer une interface ou un résultat avec permission. |
| Apprentissage interne | Garder une preuve utile sans publication. |

---

## Décision de publication

| Situation | Décision |
|---|---|
| Client autorise la publication | Fiche publique ou étude de cas. |
| Client autorise seulement certains éléments | Publication partielle ou anonymisée. |
| Client n’autorise pas la publication | Référence privée ou apprentissage interne. |
| Données sensibles présentes | Retirer, anonymiser ou garder privé. |
| Résultat encore incertain | Attendre avant de publier. |

---

## Garde-fous

- Ne pas demander une preuve avant que la livraison soit acceptée.
- Ne pas publier sans permission explicite.
- Ne pas exposer de données client sensibles.
- Ne pas exagérer les résultats.
- Ne pas transformer le portfolio en vitrine technique vide de contexte.
- Ne pas publier la mécanique interne MAD DevOps.

---

## Critère de réussite

Une preuve client est valide si :

1. elle respecte le client;
2. elle montre un problème réel;
3. elle explique la valeur livrée;
4. elle reste véridique;
5. elle protège les informations sensibles;
6. elle peut soutenir une discussion commerciale future.
