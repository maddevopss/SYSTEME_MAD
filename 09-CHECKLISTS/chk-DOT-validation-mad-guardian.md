# CHK-DOT — Validation MAD Guardian

## Statut de l’identifiant

`DOT` est un identifiant temporaire en attente d’attribution dans le registre documentaire. Il est conservé afin d’éviter une rupture de liens.

## Analyse d’impact

- [ ] Les fichiers modifiés sont identifiés.
- [ ] Les domaines touchés sont déterminés.
- [ ] Les gates non applicables sont justifiés.
- [ ] Les changements sensibles sont escaladés vers le profil approprié.

## Exécution FAST

- [ ] Le lint applicable passe.
- [ ] Le build ciblé passe.
- [ ] Les guards structurels passent.
- [ ] Les tests unitaires impactés passent.
- [ ] Les contrats concernés sont validés.
- [ ] Le scan léger de secrets passe.
- [ ] Les tests orphelins sont vérifiés.

## Résultat

- [ ] Un état autorisé est attribué.
- [ ] Les erreurs et réserves sont documentées.
- [ ] Les preuves sont reliées à l’exécution.
- [ ] Aucune conclusion ne dépasse les preuves disponibles.

> Cette checklist guide l’exécution, mais ne constitue jamais une preuve d’exécution en soi.
