# Décision — conservation intégrale des idées MADSuite

Toutes les idées du lot de juillet 2026 sont conservées. Aucune ne sera oubliée ni supprimée du registre.

Leur intégration peut prendre différentes formes :

- fondation du cœur;
- module optionnel;
- outil interne;
- capacité de l’agent de bureau;
- service spécialisé;
- prototype;
- programme de recherche;
- idée rejetée avec justification, sans effacement de l’historique.

Cette décision ne constitue pas une autorisation d’intégrer directement les extraits de code reçus. Le standard MADPROOF demeure obligatoire.
