# Tableau de bord CerveauMAD

## Objectif

Fournir une vue simple de l’état du registre CerveauMAD afin de piloter les entrées, les priorités, les décisions et les actions à venir.

Ce tableau de bord complète le registre et la revue CerveauMAD.

## Principe

```text
Ce qui n’est pas visible ne se pilote pas.
```

Le tableau de bord ne remplace pas le registre.

Il sert à voir rapidement :

- ce qui est nouveau;
- ce qui est bloqué;
- ce qui doit être clarifié;
- ce qui doit être planifié;
- ce qui doit être fermé;
- ce qui mérite une décision.

## Revue rapide

À chaque revue CerveauMAD, mettre à jour :

1. la santé du registre;
2. les P0 / P1;
3. les entrées à clarifier;
4. les entrées à planifier;
5. les entrées à fermer ou refuser;
6. les décisions à créer;
7. les actions de la semaine.

---

## Critère de réussite

Le tableau de bord est utile si une revue rapide permet de savoir quoi traiter, quoi clarifier, quoi fermer et quoi prioriser.
