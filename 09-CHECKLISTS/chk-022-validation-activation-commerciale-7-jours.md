# CHK-022 — Validation activation commerciale 7 jours

## Objectif

Valider qu’une activation commerciale de 7 jours a été exécutée de façon utile, claire et actionnable.

Cette checklist sert à confirmer que le mini-sprint commercial a produit du mouvement réel : pistes, opportunités qualifiées, actions, pipeline mis à jour et prochaine semaine clarifiée.

## Principe

```text
Une activation commerciale est valide si elle crée du mouvement réel, pas seulement un document rempli.
```

---

## Checklist

### 1. Préparation

- [ ] La période de 7 jours est définie.
- [ ] L’objectif principal est clair.
- [ ] Le pipeline commercial est ouvert ou mis à jour.
- [ ] Le tableau de bord commercial est consulté.

---

### 2. Pistes identifiées

- [ ] Des pistes ou contacts réels sont listés.
- [ ] La source de chaque piste est indiquée.
- [ ] Les pistes ne sont pas uniquement des idées vagues.
- [ ] Les pistes non alignées sont retirées ou archivées.

---

### 3. Opportunités qualifiées

- [ ] Les opportunités prioritaires ont une fiche.
- [ ] Le besoin pressenti est formulé simplement.
- [ ] La prochaine action est claire.
- [ ] Les opportunités trop floues sont fermées ou remises à clarifier.

---

### 4. Validation des opportunités

- [ ] CHK-021 est utilisée pour les opportunités importantes.
- [ ] Les priorités P0/P1 sont justifiées.
- [ ] Aucune opportunité n’avance sans besoin minimalement clair.
- [ ] Aucune promesse exagérée n’est créée.

---

### 5. Actions commerciales

- [ ] Les suivis ou actions retenus sont préparés.
- [ ] Les messages restent simples et humains.
- [ ] Les actions réalisées sont notées.
- [ ] Les réponses ou absences de réponse sont consignées.

---

### 6. Pipeline et tableau de bord

- [ ] Le pipeline est mis à jour.
- [ ] Les opportunités sont dans la bonne étape.
- [ ] Les pistes mortes sont archivées.
- [ ] Le tableau de bord reflète l’état réel.

---

### 7. Revue finale

- [ ] La revue finale est complétée.
- [ ] Les apprentissages sont notés.
- [ ] Les actions de la semaine suivante sont définies.
- [ ] Les documents nécessaires sont mis à jour.

---

## Résultat de validation

- [ ] Activation validée
- [ ] Activation partielle
- [ ] Activation à reprendre
- [ ] Activation non concluante

---

## Critères d’acceptation

L’activation est acceptée si :

1. des pistes réelles ont été identifiées;
2. les opportunités importantes ont été qualifiées;
3. les fausses priorités ont été filtrées;
4. le pipeline est à jour;
5. une revue finale existe;
6. la prochaine action commerciale est claire.
