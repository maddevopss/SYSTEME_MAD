# Exemple — Offre terrain MAD DevOps

## Objectif

Montrer à quoi ressemble une offre terrain courte après qualification d’une opportunité.

Cet exemple sert de référence pour utiliser le template de message d’offre courte sans écrire une proposition complète trop tôt.

## Contexte simulé

```text
Contact : propriétaire d’une petite entreprise de services
Besoin : clarifier le site Web et réduire les demandes floues
Offre possible : mini-diagnostic + amélioration ciblée de la page d’accueil
Prochaine étape : appel court de cadrage
```

---

## Message exemple

```text
Bonjour [Nom],

Merci pour les détails.

Voici ce que je comprends : ton site présente ton entreprise, mais il ne guide pas assez clairement les visiteurs vers une demande concrète.

Je pense pouvoir t’aider avec un mini-diagnostic de ta page d’accueil, suivi d’une amélioration ciblée du message et des appels à l’action.

La meilleure prochaine étape serait un court appel de cadrage pour confirmer le besoin, regarder ce qui bloque et voir si un petit mandat précis ferait du sens.

Si ça te convient, je peux te proposer un moment cette semaine.

Merci,
Marc-André
MAD DevOps
```

---

## Pourquoi cet exemple fonctionne

- Le besoin est résumé simplement.
- L’aide proposée reste limitée et réaliste.
- Le message ne promet pas un résultat magique.
- La prochaine étape est claire.
- La proposition complète n’est pas envoyée trop tôt.

---

## Validation rapide

Avant envoi, vérifier avec CHK-024 :

```text
Besoin clair : oui
Aide réaliste : oui
Une seule prochaine étape : oui
Message court : oui
Aucune promesse exagérée : oui
```
