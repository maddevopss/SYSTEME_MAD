# PLAY-022 — Audit chaine commerciale MAD DevOps

## Objectif

Auditer la chaine commerciale MAD DevOps pour verifier qu elle est complete, coherente et utilisable.

---

## Principe

```text
Verifier la chaine.
Trouver les trous.
Fermer les ecarts.
Passer a l usage.
```

---

# 1. Lire la synthese

Lire :

```text
synthese-chaine-commerciale-mad-devops.md
```

---

# 2. Verifier les points d entree

Verifier que les documents couvrent :

- presence Web;
- demandes entrantes;
- prospection;
- qualification;
- appel decouverte;
- proposition;
- livraison;
- temoignage;
- portfolio;
- cockpit commercial.

---

# 3. Verifier les index

Verifier :

- guides;
- templates;
- playbooks;
- checklists.

---

# 4. Noter les ecarts

Pour chaque ecart, noter :

- document concerne;
- probleme;
- correction requise;
- priorite.

---

# 5. Fermer ou reporter

A la fin, choisir :

- chaine validee;
- corrections mineures;
- corrections majeures;
- bloc a reprendre.
