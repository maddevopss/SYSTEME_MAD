# Principes de séparation des PR — programme d’idées

- une PR par dépôt;
- une intention principale par PR;
- documentation séparée du code lorsque la portée le justifie;
- migrations séparées des refontes sans lien;
- preuves et retour arrière dans chaque PR;
- aucune fusion automatique d’une PR qui mélange des modules indépendants.
