# Template — Formulaire de contact MAD DevOps

## Objectif

Définir les champs minimaux d’un formulaire de contact pour recevoir une demande claire sans rendre l’entrée trop lourde.

---

## Champs recommandés

| Champ | Type | Obligatoire |
|---|---|---|
| Nom | Texte | Oui |
| Courriel | Courriel | Oui |
| Organisation | Texte | Non |
| Type de besoin | Choix | Oui |
| Message | Texte long | Oui |
| Urgence | Choix | Non |
| Budget approximatif | Choix optionnel | Non |
| Consentement à être recontacté | Case à cocher | Oui |

---

## Choix — Type de besoin

- Créer un outil Web ou mobile.
- Automatiser une tâche répétitive.
- Clarifier une idée de projet.
- Améliorer un processus existant.
- Obtenir une première estimation.
- Autre.

---

## Message d’aide

```text
Décrivez brièvement ce que vous aimeriez améliorer, simplifier ou automatiser.
Pas besoin d’utiliser des termes techniques.
```

---

## Message de confirmation

```text
Merci pour votre message.
Je vais prendre le temps de lire votre demande et vous répondre avec une prochaine étape claire.
```
