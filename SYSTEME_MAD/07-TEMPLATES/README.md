# Index — Templates

## Rôle du dossier

Ce dossier contient les modèles réutilisables du Système MAD.

Un template sert à accélérer la création d’un document, d’un cadrage, d’un suivi, d’une livraison ou d’un projet sans repartir de zéro.

## Templates prioritaires

### Démarrage projet

```text
SYSTEME_MAD/07-TEMPLATES/starter-kit-projet-mad-devops.md
```

Il sert à démarrer un nouveau projet MAD DevOps avec une base claire.

### Parcours client

```text
SYSTEME_MAD/07-TEMPLATES/template-cadrage-client-mad-devops.md
SYSTEME_MAD/07-TEMPLATES/template-proposition-client-mad-devops.md
SYSTEME_MAD/07-TEMPLATES/template-suivis-client-mad-devops.md
SYSTEME_MAD/07-TEMPLATES/template-fiche-projet-client-mad-devops.md
SYSTEME_MAD/07-TEMPLATES/template-fiche-apprentissage-opportunite-mad-devops.md
SYSTEME_MAD/07-TEMPLATES/template-tableau-suivi-clients-mad-devops.md
```

Ces templates soutiennent le parcours client, du premier contact au suivi post-livraison.

### Pilotage MAD DevOps

```text
SYSTEME_MAD/07-TEMPLATES/template-revue-hebdomadaire-pilotage-mad-devops.md
SYSTEME_MAD/07-TEMPLATES/template-lancement-pilotage-solo-micro-equipe-mad-devops.md

```

Ces templates permettent d’utiliser le pilotage MAD DevOps de façon concrète, légère et non punitive.

---

## Règles d’usage

- Copier le template dans le projet cible avant adaptation.
- Adapter le contenu au besoin réel.
- Remplacer les placeholders avant une livraison.
- Relier les templates aux standards, checklists, guides et playbooks pertinents.
- Garder les templates simples et maintenables.
- Supprimer ou simplifier un template qui devient plus lourd qu’utile.
