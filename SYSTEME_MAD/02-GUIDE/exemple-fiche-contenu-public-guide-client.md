# Exemple — Fiche contenu public Guide client

## Objectif

Montrer comment utiliser le template de fiche contenu public candidat avec l’idée de page Guide client rapide.

Cet exemple sert à trier l’idée avant toute publication ou implémentation Web.

## Fiche remplie

```text
Date : 2026-07-01
Titre / idée : Guide client rapide
Type de contenu : page Web publique
Public visé : visiteurs, prospects, petites entreprises, travailleurs autonomes
Besoin client visé : comprendre si MAD DevOps peut aider et quelle prochaine étape choisir
Valeur pour le client : clarification rapide sans jargon
Risque de révéler la méthode interne : moyen
Éléments à garder privés : CerveauMAD, Machine à clients, playbooks, checklists, logique complète de qualification
Version publique possible : page simple d’orientation par types de besoins
Prochaine étape : reporter jusqu’à reprise devant l’ordinateur, puis valider avec CHK-025 et CHK-026
Statut : Reporté
```

---

## Décision

```text
Ne pas publier la méthode.
Publier seulement une orientation client simple.
Garder la mécanique interne privée.
```

---

## Pourquoi cette décision

- L’idée est utile pour les visiteurs.
- Le contenu peut améliorer les demandes entrantes.
- Le risque existe si la page explique trop le système interne.
- La version publique doit rester centrée sur les besoins du client.
- La publication doit attendre une validation devant l’ordinateur.

---

## Validation requise

Avant publication :

```text
CHK-025 — Validation page Guide client rapide
CHK-026 — Validation contenu public MAD DevOps
```
